[E7 0.2.7](https://github.com/e7lang/e7/releases/tag/v0.2.7) is a compiler-only release. It closes TypeScript gaps
that the [coverage table](/docs/reference/TYPESCRIPT) found, ahead of the 0.3 work on generators, `async` and
regular expressions. The VM did not change, so modules from this compiler run on every 0.2.x VM in the field.

<!-- truncate -->

The table went from 117 to 129 supported features out of 250.

```ts
interface Tree { label: string; children: Tree[] }           // recursive interfaces
enum Access { Read = 1 << 0, Write = 1 << 1, All = Read | Write }  // constant enum expressions

function size(t: Tree): number {
  return 1 + t.children.reduce((n, c) => n + size(c), 0);
}

let host = "", port = 0;
({ host, port = 443 } = { host: "api.example" } as { host: string; port?: number | undefined });

let retries = 0;
retries ||= 3;                                               // logical assignment

class Session {
  #token = "";
  get #expired(): boolean { return this.#token === ""; }     // private accessors
  status(): string { return this.#expired ? "expired" : "ok"; }
}

const tree: Tree = { label: "root", children: [{ label: "leaf", children: [] }] };
console.log(size(tree), Access.All, host, port, retries, new Session().status());
```

- **Types**: recursive interfaces and type aliases, including mutually recursive and generic ones.
- **Syntax**: destructuring assignment with object patterns, defaults and rest; `||=` and `&&=`; the comma and
  `void` operators; constant expressions in enum members; private accessors.
- **Modules**: default exports and imports, re-exports (`export * from`, `export { x } from`), side-effect imports,
  and classes, types and enums through `import * as ns`. `import type` is now erased as TypeScript erases it: a module
  reached only through it no longer runs.
- **Narrowing**: `x = x === null ? [] : x` and static field paths such as `C.#instance`.

The [0.3 design](/docs/reference/DESIGN-0.3) describes what comes next: coroutines for generators and `async`
(with the host as the event loop), a budget-bounded regular expression engine, and literal types.
