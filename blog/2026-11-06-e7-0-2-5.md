[E7 0.2.5](https://github.com/e7lang/e7/releases/tag/v0.2.5) is about two things: writing more of the TypeScript you
already write, and trusting that it behaves exactly as it does on Node.js. It is compatible with 0.2.0 and 0.2.1.

<!-- truncate -->

## More TypeScript

Before this release we probed 59 common TypeScript patterns: 33 were rejected. Now 14 are, and they are the ones
that need dynamic values (unions like `string | number`, `Record`, `unknown`, `keyof`), regular expressions,
generators or overloads.

```ts
abstract class Shape {
  abstract area(): number;
  get label(): string { return `shape(${this.area().toFixed(1)})`; }
}
class Circle extends Shape {
  #r: number;
  constructor(r: number) { super(); this.#r = r; }
  area(): number { return Math.PI * this.#r ** 2; }
}

function largest<T extends Shape>(items: T[]): T | null {
  let best: T | null = null;
  for (const s of items) if (best === null || s.area() > best.area()) best = s;
  return best;
}

const [first, ...rest] = [new Circle(1), new Circle(3), new Circle(2)];
try {
  console.log(largest([first, ...rest])?.label, largest([])?.area().toFixed(2), rest.length);
} finally {
  console.log("done");
}
```

- **Generics**: functions, classes, interfaces and type aliases, with constraints, defaults and inference. They are
  compiled by monomorphization, one copy per type, so the VM did not change.
- **`finally`**, getters and setters, `abstract`, `#private`, `static {}` blocks, inherited static members, and a
  class's own `toString()` in string conversions.
- Defaults and rest in destructuring, defaults in arrow functions, `a?.[i]`, spread arguments, method shorthand,
  `flatMap`, `Object.entries`, `replace` with a function.

## Identical to Node.js

- **`console.log`** now prints exactly what Node.js prints: line breaking at 80 columns, aligned number columns,
  `Map(2) { 'a' => 1 }`, class names, depth limits. 116,000 random values were compared.
- **Math** functions and `**` use V8's own fdlibm port, so `Math.expm1(1)` is `1.718281828459045` on every platform,
  not whatever the platform's C library returns.
- A **differential fuzzer** generates random programs in the E7 subset, runs them on e7 and on Node.js, and minimizes
  any difference. About 70,000 programs during this release found ten library differences and eight compiler issues;
  all are fixed. It now runs every night.

## Sturdier

New checks run in CI: a GC stress mode that collects at every opportunity, allocation-failure injection at every
allocation with a heap consistency check, the whole test suite with a budget slice of one instruction and with a
debugger stepping through everything, a 100,000-call soak test, threads under TSan, and modules from the new
compiler run on the previous release's VM. They found real bugs, among them a compiler data race, a module leak after
a failed load, and garbage that could not be collected while a sort comparator ran. All fixed.

E7 is still 0.x: tested and hardened, waiting for its first production pilot.
