[E7 0.3](https://github.com/e7lang/e7/releases/tag/v0.3.0) completes the language for what E7 scripts do:
signing and verification, protocol parsing, business rules. Generators, `async` / `await` and regular
expressions now compile and behave exactly as on Node.js, and literal types are checked as tsc checks them.

<!-- truncate -->

The [TypeScript coverage table](/docs/reference/TYPESCRIPT) went from 129 to 153 supported features out of
250. [What is supported](/docs/supported) has the summary of what works and what does not, and why.

```ts
function* pages(total: number, size: number): Generator<[number, number]> {
  for (let start = 0; start < total; start += size) yield [start, Math.min(start + size, total)];
}
async function main(): Promise<void> {
  const ids: string[] = [];
  for (const [from, to] of pages(25, 10)) ids.push(`${from}-${to}`);
  const line = "2026-11-06 ERROR db: timeout";
  const m = /^(?<date>\S+) (?<level>[A-Z]+)/.exec(line);
  console.log(ids, m?.groups?.level, await Promise.resolve(42));   // [ '0-10', '10-20', '20-25' ] ERROR 42
}
main();
```

## What is new

- **Generators**: `function*`, `yield*`, `for...of`, spread and destructuring over generators and over classes with a
  `*[Symbol.iterator]()` method.
- **`async` / `await`**: async functions, methods and arrows, `Promise` with `then` / `all` / `allSettled` / `any` /
  `race`, top-level `await`, `for await`. The VM runs the promise jobs of the ECMAScript specification, so
  callbacks run in the same order as on Node.js.
- **The app is the event loop.** A host function declared as `declare function fetchKey(id: string):
  Promise<Uint8Array>` is called by the script; the app settles it later, and the call reports that it is waiting
  (`E7_PENDING`). Every binding wraps this in its own model: Kotlin and Java futures, Swift `async`, C# `Task`
  ([embedding guide](/docs/reference/EMBEDDING)).
- **Regular expressions** with E7's own engine: literals are checked when compiling, named groups are typed, and
  every matching step is charged to the instruction budget, so a catastrophic pattern ends the call instead of
  freezing the app.
- **Literal types** (`"GET" | "POST"`, `0 | 1`), `as const`, exhaustive `switch` with `never`, type predicates and
  assertion functions, tagged templates, computed keys, more typed arrays, `structuredClone`, `Error` `cause`.
- Objects now keep a property that holds `undefined` (`{ a: undefined }` prints as on Node.js).

## Compatibility

Modules from 0.2 compilers run on the 0.3 VM unchanged. A 0.3 module that uses none of the new features is
still bytecode format 2 and runs on 0.2 VMs; one that does is format 3, which 0.2 VMs refuse at load time with a
clear version error. The [changelog](https://github.com/e7lang/e7/blob/main/CHANGELOG.md) lists every change,
and two independent security reviews of the new VM code are recorded in the
[verification record](/docs/reference/PRODUCTION).

Not in 0.3: async generators and getters in object literals, planned for a later release.
