E7 0.1.0 is the first release of E7: a strict subset of TypeScript that compiles to verified bytecode and runs
in e7vm, a small virtual machine you embed in Android, iOS, Windows, macOS and Linux apps. Scripts are compiled on
your server, signed, shipped to the app and run in a sandbox, so request signing, verification, pricing and other
business rules can change without an app release.

## What you can write

Everyday TypeScript, checked when the script is compiled:

- **Types:** interfaces and type aliases (also generic and recursive), generics with constraints, literal types and
  `as const`, enums, `T | null | undefined`, narrowing with `switch` exhaustiveness (`never` in `default`).
- **Classes and objects:** inheritance, `abstract`, getters and setters (also in object literals), `#private`
  members, `static` blocks, parameter properties.
- **Iteration and async:** generators, `async` / `await`, `Promise.all` / `allSettled` / `any` / `race`, async
  generators and `for await`. Promise callbacks run in the same order as in Node.js; the app is the event loop and
  provides asynchronous operations as host functions that return promises.
- **Library:** arrays (including the ES2023 copying methods), strings, `Map`, `Set`, `Date` (UTC), `JSON.parse(text)
  as T` validated against `T`, `BigInt`, typed arrays, `TextEncoder` / `TextDecoder`, `structuredClone`, plus
  `e7:crypto` with modern algorithms only (SHA-2, HMAC, HKDF, PBKDF2, AES-GCM, ChaCha20-Poly1305, Ed25519, X25519), `e7:encoding`,
  `e7:json` and `e7:test`.

```ts
async function* lines(pages: string[][]): AsyncGenerator<string, void, unknown> {
  for (const page of pages) yield* page;          // a host call would fetch each page
}
const stats = {
  count: 0,
  bytes: 0,
  get average(): number { return this.count === 0 ? 0 : this.bytes / this.count; },
};
for await (const line of lines([["a", "bcd"], ["ef"]])) {
  stats.count++;
  stats.bytes += line.length;
}
console.log(stats.average, JSON.stringify(stats));   // 2 {"count":3,"bytes":6,"average":2}
```

[TypeScript coverage](/docs/reference/TYPESCRIPT) lists 250 TypeScript features: 154 are supported, 16 partly, and
the rest are rejected at compile time with a reason and what to write instead. [What is supported](/docs/supported)
has the summary.

## Why E7

- **Every type is known when the script is compiled.** Mistakes are compile errors, and the VM verifies the bytecode
  again when it loads it, so a script cannot confuse an integer with a pointer or read outside its memory.
- **It behaves like JavaScript.** Every test is compared with Node.js, down to the order of promise callbacks. What
  E7 cannot run exactly like JavaScript is a compile error, not a silent difference.
- **A sandbox the app controls:** instruction budgets and memory limits, no file, network or system access unless
  the app provides a function for it, signed bytecode, and keys the app keeps (scripts see only a handle). Eight
  security reviews and continuous fuzzing are documented in [PRODUCTION.md](/docs/reference/PRODUCTION).
- **Small and portable:** C++17, no JIT, one C API with Kotlin/Java, Swift and C# bindings; the same compiler and VM
  also run as WebAssembly in the [playground](/playground) and the VS Code extension.
- **Friendly to AI assistants:** the [E7 skill](/docs/ai) tells an assistant what E7 accepts and how to rewrite what
  it does not.

## What E7 does not do

E7 rejects what it cannot check before the script runs: `any`, unions of different types, index signatures and
`Record`, type-level computation (mapped, conditional, `keyof` types), `Symbol`, `Proxy`, `eval`, `for...in`,
decorators, namespaces and `var`. Regular expressions are left out to keep the runtime small: string methods
(`indexOf`, `split`, `replaceAll`) cover the common cases. Timers and I/O belong to the app. Locale formatting (`Intl`) and weak references
wait for a later release.

## Get it

- **Command line:** the archives for Linux, macOS and Windows on the
  [release](https://github.com/e7lang/e7/releases/tag/v0.1.0), its Homebrew formula and Scoop manifest; see
  [Getting started](/docs/getting-started).
- **In your app:** Maven (`org.e7vm:e7vm-android:0.1.0`), Swift Package Manager, NuGet (`E7VM`); see
  [Calling scripts from your app](/docs/host-apps).
- **No install:** the [playground](/playground).

E7 is versioned 0.x on purpose: it is tested and hardened but has not run in production yet. The next step is a
production pilot, in which an app runs E7 scripts next to its existing code and compares the results.
